          ✨ Step 04 · Dual Attention Gate
          Tensor: [B, 1280, 7, 7]
          🧠 Convolutional Block Attention Module (CBAM)

          Sequential dual-attention mechanism: First, the Channel Attention Module (CAM) computes average and max pooled descriptors across spatial dimensions to learn WHAT features to emphasize. Then, the Spatial Attention Module (SAM) computes channel-wise pooled maps with a 7×7 conv to learn WHERE the lesion is located.

          Type: Channel + Spatial Attention
          Parameters: ~16.4K added
          Impact: 99.38% Acc · Peak F1-Score
          Grad-CAM: Tightest focus on lesions
          Model Variants

          Three attention variants tested under identical conditions — same data, same hyperparameters.

          Baseline
          EfficientNet-B0
          99.23%

          Standard pretrained EfficientNet-B0 with a custom classifier head. No attention module — serves as the control.

          SE Net
          Squeeze-Excitation
          99.34%

          Adds channel-wise recalibration (squeeze-and-excitation) after the backbone. Learns which feature maps to emphasise.

          🏆 Best
          CBAM
          99.38%

          Convolutional Block Attention Module — sequential channel and spatial attention. Achieves the highest accuracy and F1.
