          🔴 CBAM

          99.38% accuracy — Best performing

          Convolutional Block Attention Module applies sequential channel-wise (Squeeze-Excitation with both avg+max pool) followed by spatial attention (7×7 conv on pooled maps). Captures both what and where to attend.

          🟢 SE Block

          ~98.8% accuracy — Channel-only attention

          Squeeze-Excitation recalibrates channel-wise feature responses. Global average pooling squeezes spatial dimensions, then two fully-connected layers learn per-channel weights. No spatial attention component.

          ⚪ Baseline

          ~97.5% accuracy — No attention

          Pure EfficientNet-B0 backbone with the classification head but no attention module. The identity block passes features through unchanged. Serves as the ablation control for quantifying attention benefits.
